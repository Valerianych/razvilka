# Развилка

Редактор ветвящихся визуальных новелл на русском языке. На карте можно соединять сцены, подписывать варианты выбора, отмечать ключевые моменты и вести разные пути к своим финалам. У каждого узла могут быть реплики и связанные записи о персонажах, местах, предметах или событиях.

## Запуск

Откройте [Развилка.html](./Развилка.html) на GitHub, нажмите **Download raw file** и откройте скачанный файл в браузере. В него встроены код и иллюстрации, поэтому он работает без подключения к интернету.

Для работы с исходниками скачайте репозиторий целиком и откройте [index.html](./index.html). Сборка и установка зависимостей не требуются.

## Первая история

1. В проекте «Тихий эфир» нажмите **Пройти историю**, чтобы попробовать три маршрута.
2. Выберите **Мои проекты → Новый проект**, чтобы начать свою новеллу.
3. В **Базе лора** создайте персонажа или место. Из записи можно сразу создать связанную сцену.
4. На **Карте сюжета** нажмите **Добавить узел**. Укажите, из какого узла в него ведёт переход и какой выбор увидит читатель.

Изменения сохраняются в хранилище текущего браузера. Для резервной копии или переноса на другое устройство используйте **Файл → Скачать проект**. Восстановить копию можно через **Файл → Открыть из файла**.
